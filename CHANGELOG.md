# Changelog

## 1.0.0
- Первый выпуск: NTP по UDP для ESP32 и ESP8266 без NTPClient.
- Сверка раз в час без остановки программы, повторы при ошибке (10 с, потом 60 с), синхронизация вручную `sync()`.
- Поправка на задержку сети и доли секунды сервера, проверка исходной метки (чужой ответ отбрасывается), защита от kiss-o'-death.
- Поля даты и времени, день недели, часовой пояс по умолчанию UTC+5 (Казахстан), переход через 2036 год.
- Понятные ошибки и `diagnose()` на русском, казахском и английском.
